> *"The year is 1200 BC. The great palaces of Mycenae crumble in smoke. Hattusa is abandoned to ash. Overseas trade in tin is severed, and mysterious fleets with horned helmets appear on the western horizon. As Burna the Khabir, you must lead a Levantine redoubt from the collapse of the Bronze Age to the dawn of the Iron Age."*

**Ashes of Bronze: The Iron Dawn** is a classic 1990s-style SVGA Real-Time Strategy game built entirely in TypeScript and HTML5 Canvas. Inspired by golden-era masterpieces such as *Age of Empires*, *Dune II*, and *Caesar III*, it combines strategic base building, resource logistics, tactical AI warfare, and dynamic narrative chronicles.

---

## ⚔️ Key Features

- **Late Bronze Age Collapse Setting (1200 – 1100 BC):**
  Experience the historical transition from fragile bronze dependency to the discovery of iron smelting across a three-act campaign (10 handcrafted historical scenarios).
- **Procedural 2.5D SVGA Pixel Art Engine:**
  Authentic 1990s PC strategy aesthetic rendered directly onto an HTML5 Canvas with custom shaders, dynamic elevation slopes, volumetric shadows, construction scaffolding, and water reflections.
- **Resource Logistics & Economy:**
  Manage Wood, Food, Clay, Copper, and scarce Cassiterite Tin. Smelt Bronze, quarry stone for Cyclopean ramparts, and discover the secrets of Hematite iron forging.
- **Full Historical Warfare:**
  Command Spearmen Phalanxes, Slingers, Composite Bowmen, Bronze Khopesh Warriors, and Royal Chariots against Sea Peoples Shardana reavers, horned galleys, and invading armadas.
- **Wildlife & Desert Predators:**
  Venture into the steppe at your peril: prowling Levantine Lions sortie from indestructible mountain crags to hunt down stray workers and scouts.
- **Interactive Strategic Campaign Map:**
  A hand-drawn cartographic map of the Eastern Mediterranean (1200 BC) featuring detailed coastlines, ancient metropolises (Hattusa, Ugarit, Byblos, Tyre, Pi-Ramesses), bathymetric sea reefs, mountain relief, and trade routes.
- **Synthesized Web Audio Engine:**
  Procedurally synthesized period audio effects: bronze clashes, war horns, chariot rumble, arrows in flight, roaring predatory lions, and victory fanfares.

## 🛠️ Development & Running Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/lhackyup/ashes-of-bronze.git
cd ashes-of-bronze

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open your browser at `http://localhost:5173/` to play.

### Production Build
```bash
npm run build
npm run preview
```
