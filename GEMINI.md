# Project Guidelines: Ashes of Bronze

## Language & Localization Rules
- **All in-game content MUST be written in English**:
  - Narrative text, story briefings, debriefings, chronicles, and lore.
  - UI labels, modal titles, button labels, tabs, and notifications.
  - Scenario definitions (`.json` files), advisor messages, objectives, and warnings.
  - Code comments, identifiers, variable names, and documentation.
- When communicating with the user, reply in Italian (using the informal "tu"), but **never inject Italian text into the game codebase, assets, or data files**. All game text must remain strictly in English.
